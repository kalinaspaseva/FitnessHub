# 🏋️‍♂️ FitnessHUB — Management Dashboard

## Overview
FitnessHUB is a modern, web-based management platform built for fitness centers and gyms using Django. It enables gym administrators to effortlessly manage trainers, client registries, and workout schedules through an intuitive dark-mode interface. The system features dynamic business logic that strictly enforces trainer availability, working hours, and structured booking slots to ensure seamless operational efficiency.

---

## Key Features
* **📊 Real-time Dashboard:** Instantly track active trainers, registered clients, and total upcoming sessions with high-visibility key metrics.
* **👨‍🏫 Trainer Portfolio & Schedules:** Dedicated profile pages for each trainer showing their specialization, assigned working hours, active workdays, and personalized session lists.
* **👥 Client Registry:** Simplified onboarding workflow to register new gym members directly from the application interface.
* **📅 Smart Session Booking:** Built-in validation logic preventing out-of-bounds schedule requests by ensuring bookings match each trainer's working hours, active days, and half-hour time slots.
* **❌ Session Management:** Seamless one-click session cancellation and workflow management for staff.

---

## Technologies Used
* **Backend:** Django (Python Web Framework)
* **Frontend:** HTML5, CSS3, Google Fonts, Bootstrap 5
* **Database:** SQLite (Embedded Development Database)
